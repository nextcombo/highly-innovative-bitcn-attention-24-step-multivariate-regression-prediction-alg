# [Highly innovative] BiTCN-Attention 24-step multivariate regression prediction algorithm, MATLAB code.

The program platform requires MATLAB 2023 or above.
We propose a forward-looking 24-step multivariate time series regression prediction algorithm based on the Bidirectional Time Convolutional Network (BiTCN) with attention mechanism, which has extremely high innovativeness.
Features: Multivariate feature input and single sequence variable output. The model predicts the next day's data by inputting the features from the previous day, achieving a 24-step forward prediction. It provides results for MAPE, RMSE, MAE, etc.
Innovations include:
① Bidirectional Time Convolution: BiTCN introduces bidirectional time convolution, combining the information of past and future time series, enabling the model to better capture the temporal patterns in the time series. Traditional unidirectional convolution only focuses on local context information, while bidirectional convolution can capture important features from multiple directions.
② Residual connection: The residual connection used in the model helps alleviate gradient vanishing issues, allowing the network to learn feature representations deeper into the network. The introduction of residual connections makes the model easier to train and accelerates the convergence process.
③ Multiscale Convolution: BiTCN can capture different levels of time features through stacking multiple different scale convolution layers. This multiscale convolution strategy helps the model understand different frequencies and temporal patterns in the time series more comprehensively.
④ Recursive Stacking: The model can improve its expressive capacity by recursively stacking multiple BiTCN modules. Recursive stacking allows the model to extract and fuse features at different abstraction levels step by step, thereby better predicting time series.
Applicable fields:
Wind speed prediction, photovoltaic power prediction, power generation power prediction, carbon price prediction, and other applications.
Usage convenience:
Directly import data into the Excel table without significant modification to the program. The internal comments are detailed and easy to understand.
Dataset format:
The previous day, there were 18 meteorological features, with sampling time set to 24 hours. The output was the power output for the next day's 24-hour period, which is equivalent to 18×24 inputs and 1×24 outputs, totaling 75 such samples.
